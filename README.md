# AI vs Human Text Detection

## Overview
This project implements a machine learning model to classify AI-generated and human-written text.

## Features
- Text preprocessing
- Feature extraction
- Machine Learning classification
- Performance evaluation using Accuracy and F1-score

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Results
The model was evaluated using Accuracy and F1-score to compare AI-generated and human-written text.
